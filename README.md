# Agenda Revital

Sistema de agendamiento de citas médicas para Revital Centros Médicos, Guayaquil.

## Empezar

```bash
git init
git add . && git commit -m "Documentación base del proyecto"
claude
```

Después seguí las sesiones de `docs/PROMPTS.md`, una por una.

## Documentación

| Archivo | Contenido |
|---|---|
| `CLAUDE.md` | Índice y reglas del proyecto. Claude Code lo lee solo. |
| `docs/ESPECIFICACION.md` | Especificación completa: datos, reglas, endpoints, permisos |
| `docs/TOKENS_DISENO.md` | Identidad visual y accesibilidad |
| `docs/PROMPTS.md` | Los prompts de cada sesión, en orden |
| `docs/plantillas/convenios.xlsx` | Plantilla de carga de beneficiarios por convenio |
